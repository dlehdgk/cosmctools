# Package for Cosmological model comparison (and others) from Cobaya MCMC chains

## Installation

Clone this repository and install using `pip` or `uv` (recommended)

for `pip`:

```bash
git clone https://github.com/dlehdgk/cosmctools.git
pip install -e cosmctools
```

for `uv`, recommended that you create a new environment for this package:

```bash
uv init
git clone https://github.com/dlehdgk/cosmctools.git
uv add --editable cosmctools
```

It is recommended that you install this package in editable mode as you may wish to modify the code for your specific choice of models and datasets.

There may be issues with compatibilities with the `setuptools` version if not using `uv`.

## Functionality

This is package is essentially an umbrella wrapper for multiple cosmology codes, please ensure that the original authors of the codes are cited if they have been used. This code takes MCMC chains generated by [Cobaya](https://cobaya.readthedocs.io/en/latest/index.html) developed by [J. Torrado and A. Lewis 2021](http://arxiv.org/abs/2005.05290) and is able to:

- Return constraints on requested parameters using [getdist](https://getdist.readthedocs.io/en/latest/) by [A. Lewis 2019](https://arxiv.org/abs/1910.13970).

    - You may need to add your equations for any derived parameters that have not been tracked by the sampler in `add_derived()` (more details below).

- **Not Yet Implemented**: Return triangle plots of requested parameters using `getdist`.

- Return $\chi^2$ at Maximum Likelihood (ML) or Maximum A Posteriori (MAP) points. Note that this requires that you have already ran `Cobaya` with a minimizer (`ignore_prior=True` for ML which generates a `.bestfit` file and `ignore_prior=False` for MAP generating a `.minimum` file).

    - You may need to add the names of the likelihoods used in your run if not listed in the code (more details below).

- Compute the AIC ([H. Akaike 1974](https://ieeexplore.ieee.org/document/1100705)) and DIC ([D. Spiegelhalter et al. 2002](https://academic.oup.com/jrsssb/article-abstract/64/4/583/7098621) and A. Gelman et al. 2013,
Bayesian Data Analysis, Third Edition, Section 7) of models using the `get_chi2()` function (requires that a minimizer has already been run).

    - For the method described in Spiegelhalter et al. 2002, also requires that `Cobaya` has also been installed in the environment to run an evaluation of the likelihood at the posterior mean.

- Estimate Bayesian evidence using `MCEvidence` ([A. Heavens et al. 2017](https://arxiv.org/abs/1704.03472) using the wrapper for `Cobaya` chains written by [W. Giarè](https://github.com/williamgiare/wgcosmo/tree/main/statistics/MCMC_Evidence)) through the function `get_MCE_bayes_factor()`

    - **Not Yet Implemented**: cleaning up the wrapper to be more consistent with the rest of the package.

- Estimate Bayesian evidence using the Learnt Harmonic Mean Estimator (LHME) method using [harmonic](https://github.com/astro-informatics/harmonic) ([J. McEwen et al. 2021](https://arxiv.org/abs/2111.12720)) through the function `get_LHME_bayes_factor()`

    - Uses the normalising flow model for the target density as described in [A. Polanska et al. 2024](https://arxiv.org/abs/2405.05969).

    - It will be able store the trained model for later use.

## Usage

Create a `cosmo_model` object with the file root of the `Cobaya` chains with the burnin fraction and the number of chains to be read.

If there are additional derived parameters which were not tracked in the sampling process when running `set_display_params()`, the code will automatically run `add_derived()` when it encounters such a parameter when running `get_params()`.

You must run `set_sampled_params()` prior to attempting to obtain bayesian evidence.

- If there is a prior without finite bounds (e.g. Gaussian prior), you can either set bounds manually using `"param_name":<min>/<max>` or define a confidence level using `"param_name";<confidence level>` (e.g. 0.9999995 for 5 sigmas of the prior).

    - Note that the prior bounds are only required for `MCEvidence`.

## Example

```python
from cosmctools import *

# optional argument block_num used to split the MCMC chains into smaller blocks when using harmonic to estimate evidence

lcdm = cosmo_model("./chains/lcdm", burnin=0.3, nchains=4, block_num=12).set_sampled_params([
    "H0",
    "omega_b",
    "omega_cdm",
    "tau_reio;0.9999995",
    "logA",
    "n_s",
])

cpl = cosmo_model("./chains/cpl", burnin=0.3, nchains=4, block_num=12).set_sampled_params([
    "H0",
    "omega_b",
    "omega_cdm",
    "tau_reio;0.9999995",
    "logA",
    "n_s",
    "w0_fld",
    "wa_fld",
])

## getting parameter constraints

# default 1 sigma
lcdm_params = lcdm.get_params([
    "H0",
    "Omega_m",
    "rs_d_h",
])

cpl_params = cpl.get_params([
    "H0",
    "w0_fld",
    "wa_fld",
], sigma=2)

## model comparison

### Delta chi2

# < 0 implies that the cpl model is a better fit to the data than the lcdm model

delta_chi2 = lcdm.get_delta_chi2(cpl)

### Delta AIC

# < 0 implies that the cpl model is a better fit to the data than the lcdm model

delta_aic = cpl.get_AIC() - lcdm.get_AIC()

### Delta DIC

# < 0 implies that the cpl model is a better fit to the data than the lcdm model

delta_dic = cpl.get_DIC() - lcdm.get_DIC()

### Bayes factors

# > 0 implies that the cpl model is a better fit to the data than the lcdm model

#### MCEvidence

MCE_bayes_factor = lcdm.get_MCE_bayes_factor(cpl)

#### LHME

# by default, once the model is trained, it will be saved with the same file root as the chains. Once it has been trained, having `train_model=False` (default) will attempt to load the saved model automatically.
LHME_bayes_factor = lcdm.get_LHME_bayes_factor(cpl, train_model=True)
```
